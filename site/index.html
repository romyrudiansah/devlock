DevLock
Fitur Mulai Panduan GitHub IDEN
Gratis, termasuk untuk komersial · Windows 10/11

Banyak versi PHP, Node, dan database. Jalan bersamaan. Dipilih per project.

DevLock adalah local development environment untuk Windows, alternatif Laragon, XAMPP, dan WAMP. blog.test memakai PHP 7.4 dan MySQL 5.7, sementara shop.test memakai PHP 8.4 dan PostgreSQL 18, aktif di saat yang sama.

Unduh untuk Windows Baca panduan

Installer per user tanpa hak admin, atau zip portable. Freeware, gratis untuk pribadi maupun komersial.

Versi terbaru · diunduh kali

Semua yang dibutuhkan project web, tanpa saling mengganggu

Tiap project menulis kebutuhannya di file .devlock.toml. DevLock menyiapkan versi, service, domain, dan sertifikatnya.

7.4

Multi-versi bersamaan

Tiap versi PHP punya pool php-cgi sendiri; tiap database + versi adalah instance dengan port dan data terpisah.

.test

Domain otomatis

Setiap folder di www menjadi nama.test, juga yang ada di folder grup seperti www\Client Work. Lewat file hosts, atau DNS wildcard *.test.

⇄

Shim per project

php, composer, node, npm, mysql, psql, dan lainnya otomatis memakai versi milik folder tempat Anda mengetiknya. Node.js atau Composer yang sudah terpasang di Windows bisa dipakai lewat node = "system".

🔒

HTTPS lokal

CA DevLock sendiri, sertifikat per site, dan redirect HTTP→HTTPS opsional. PHP dan Node ikut memercayainya.

DB

Database lengkap

MySQL, MariaDB, PostgreSQL, dan MongoDB, ditambah Redis atau Garnet sebagai cache. Buat, dump, dan restore database dari CLI atau GUI.

⚡

Dev server Node

dev = "npm run dev": dev server dijalankan sebagai service dan domain diarahkan ke sana. Vite diberi port tetap per site, jadi banyak project Vite tidak berebut 5173.

✉

Email & panel DB

Mailpit menangkap semua email di mail.test; Adminer di adminer.test langsung mengenali instance database Anda.

↗

Bagikan ke publik

devlock share blog membuka site lewat Cloudflare Quick Tunnel sampai Anda menekan Ctrl+C.

▤

Rapi untuk puluhan project

Project dikelompokkan per folder grup, service dibagi Web & PHP, Database & cache, dan Dev server, plus palet perintah Ctrl+K.

Satu file kecil per project

Versi PHP, Node, database, cache, web server, dan HTTPS ditulis di folder project, jadi ikut di-commit dan sama di setiap komputer tim.

# www\toko\.devlock.toml
php = "8.3"
database = "mysql@8.4"
cache = "redis@8"
dev = "npm run dev"     # Vite berjalan di samping PHP
https = true

Versi juga dibaca dari file yang sudah biasa dipakai: composer.json, .nvmrc, go.mod, .python-version, dan .java-version.

Runtime dari sumber resmi, diverifikasi

Semua runtime diunduh langsung dari penerbitnya dan dicek checksum-nya sebelum dipasang: php.net, nodejs.org, nginx.org, mariadb.org, mysql.com, postgresql.org, go.dev, Adoptium, MongoDB, dan rilis GitHub resmi.

Mulai dalam lima menit

Contoh untuk project Laravel. Semua langkah juga bisa dilakukan lewat GUI.

  1. Pasang DevLockJalankan installer dari halaman Releases, lalu buka terminal baru. 
    devlock path add       # shim php/composer/node masuk PATH
  2. Install runtime yang dibutuhkan 
    devlock install php 8.3
devlock install composer
devlock install nginx
devlock install mysql 8.4
devlock install node 22
  3. Buat project 
    devlock new laravel toko --php 8.3 --db mysql@8.4
  4. Jalankan 
    devlock start          # nginx, PHP 8.3, MySQL 8.4 → http://toko.test

Langkah lengkap, project Node, WordPress, HTTPS, dan pemecahan masalah ada di panduan.
