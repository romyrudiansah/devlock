DevLock
Fitur Mulai Panduan GitHub IDEN

Banyak versi PHP, Node, dan database, jalan bersamaan.

DevLock adalah local development environment untuk Windows, alternatif Laragon, XAMPP, dan WAMP. Tiap project memilih versinya sendiri lewat satu file kecil, dan semuanya aktif di saat yang sama.

Unduh untuk Windows Baca panduan

Windows 10/11 64-bit. Installer per user tanpa hak admin, atau zip portable.

Versi terbaru , diunduh kali

Beranda DevLock: service dikelompokkan per bagian, masing-masing dengan Start/Stop sendiri.

Tiap project membawa kebutuhannya sendiri

Versi, service, domain, dan sertifikat disiapkan dari file .devlock.toml di folder project.

Multi-versi bersamaan

Tiap versi PHP punya pool php-cgi sendiri. Tiap database dan versinya adalah instance dengan port dan folder data terpisah.

php@7.4        :9740-9743
php@8.3        :9830-9833
mariadb@11.4   :3424
postgresql@18  :5418

Domain .test dan HTTPS lokal

Setiap folder di www menjadi nama.test, termasuk yang ada di folder grup. CA DevLock membuat sertifikat per site, dan PHP serta Node ikut memercayainya.

www\shop              → shop.test
www\Client Work\crm   → crm.test

Shim per folder

php, composer, node, npm, mysql, dan psql memakai versi milik folder tempat Anda mengetiknya.

cd www\blog; php -v   # PHP 7.4
cd www\shop; php -v   # PHP 8.4

Juga tersedia

Database dan cache
MySQL, MariaDB, PostgreSQL, dan MongoDB, plus Redis atau Garnet. Buat, dump, dan restore database dari CLI atau GUI.
Dev server Node
dev = "npm run dev" dijalankan sebagai service dan domain diarahkan ke sana. Vite diberi port tetap per site, jadi banyak project Vite tidak berebut 5173.
Email dan panel database
Mailpit menangkap semua email di mail.test. Adminer di adminer.test langsung mengenali instance database Anda.
Bagikan ke publik
devlock share blog membuka site lewat Cloudflare Quick Tunnel sampai Anda menekan Ctrl+C.
Rapi untuk puluhan project
Project dikelompokkan per folder grup, service dibagi per bagian, dan palet perintah Ctrl+K menjangkau semuanya.
Pindah dari Laragon atau XAMPP
devlock import memindahkan project dari www atau htdocs tanpa menyalin file.

Satu file kecil per project

Versi PHP, Node, database, cache, web server, dan HTTPS ditulis di folder project, jadi ikut di-commit dan sama di setiap komputer tim.

# www\toko\.devlock.toml
php = "8.3"
database = "mysql@8.4"
cache = "redis@8"
dev = "npm run dev"     # Vite berjalan di samping PHP
https = true

Versi juga dibaca dari file yang sudah biasa dipakai: composer.json, .nvmrc, go.mod, .python-version, dan .java-version.

Runtime dari sumber resmi, dicek checksum-nya

Semua runtime diunduh langsung dari penerbitnya: php.net, nodejs.org, nginx.org, mariadb.org, mysql.com, postgresql.org, go.dev, Adoptium, MongoDB, dan rilis GitHub resmi.

Dari nol sampai toko.test terbuka

Contoh untuk project Laravel. Semua langkah juga bisa dilakukan lewat GUI.

  1. Pasang DevLock

    Jalankan installer dari halaman Releases, lalu buka terminal baru.

    devlock path add   # shim php/composer/node masuk PATH
  2. Install runtime yang dibutuhkan

    Sekali saja; versi yang sama dipakai bersama oleh semua project.

    devlock install php 8.3
devlock install composer
devlock install nginx
devlock install mysql 8.4
  3. Buat project

    Laravel dipasang lewat Composer milik DevLock.

    devlock new laravel toko --php 8.3 --db mysql@8.4
  4. Jalankan

    nginx, PHP 8.3, dan MySQL 8.4 menyala, lalu buka http://toko.test.

    devlock start

Project Node, WordPress, HTTPS, dan pemecahan masalah ada di panduan.

Unduh DevLock untuk Windows

Installer dan zip portable diterbitkan di GitHub Releases, masing-masing dengan checksum SHA-256. Unduh hanya dari sana.

Unduh dari GitHub Releases Lihat perubahan terbaru
  • Freeware, gratis untuk pribadi maupun komersial.
  • Portable: semua runtime dan data tinggal di folder instalasi.
  • Lokal saja: semua service hanya mendengarkan di 127.0.0.1.
  • Tanpa telemetri di aplikasi.
